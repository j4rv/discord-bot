# Privacy Policy

**Last updated:** September 18, 2026

JarvBot is an open-source, multipurpose Discord bot. This Privacy Policy explains what information JarvBot processes and stores when it is used in a Discord server.

## 1. Information We Collect

JarvBot does **not** collect, track, or log users' messages for data collection purposes.

The bot only processes information that is necessary for its features to function. This may include information such as:

* Discord server, channel, user, and role IDs required to operate configured features.
* Server configuration and preferences set by server administrators.
* Message content temporarily required by features like reminders, Mines, Message Logs, and Uwujail.
* A limited command execution log containing the user's username and the command they executed.

Command execution logs are used solely to detect and prevent abuse, including excessive command usage and possible DDoS or other attacks against the bot. The bot does not log the content of the user's messages when recording command usage.

JarvBot does not collect information for advertising, tracking, profiling, analytics, or other unrelated purposes.

## 2. Message Content

Some JarvBot features require access to message content, including features such as Mines, Message Logs, and Uwujail.

Message content is processed only when required for these features to operate.

Message content is **not persistently stored in a database** for tracking or logging purposes. When message content needs to be retained temporarily while a feature is operating, it is kept only for as long as necessary and is cleaned up when it is no longer needed.

For example, the Message Logs feature temporarily keeps message information in memory so that an edited message can be compared with its previous version. This information is not stored in a persistent database.

## 3. Command Execution Logs

JarvBot records limited information when a user executes a command.

The command log contains only:

* The user's Discord username.
* The command that was executed.

The contents of the user's message are not stored as part of this log.

These logs are used exclusively to detect and prevent abuse, such as command spam, excessive usage, and possible DDoS attacks against the bot. They are not used for advertising, profiling, analytics, or other unrelated purposes.

## 4. Data Storage

JarvBot stores only information that is necessary for the bot's functionality, such as server configuration and settings.

Temporary data used during feature execution is removed when it is no longer needed.

JarvBot does not maintain a database containing users' message history or other unnecessary user information.

## 5. Data Sharing

JarvBot does not sell, rent, or share user data with third parties for advertising, tracking, profiling, or similar purposes.

Data processed by the bot is used only to provide its functionality and to prevent abuse of the service.

## 6. Data Retention and Deletion

Data is retained only for as long as it is required for the corresponding JarvBot feature to function.

Temporary data is cleaned up after it is no longer needed. Persistent configuration data is retained only while it is necessary for the bot's configured functionality.

Command execution logs are retained only as necessary for detecting and investigating abuse and are not intended to constitute a permanent record of users' activity.

If a server removes JarvBot, server-specific data can be removed as part of the bot's cleanup procedures.
